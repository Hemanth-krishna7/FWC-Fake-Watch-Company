# **FWC (Fake Watch Company)**

Daily Project Progress

###### **Day: 6**

###### Date: **16/09/2026**



Today we continued working on the FWC (Fake Watch Company) website by adding JavaScript and reveal animations.



We first connected the project.js file with the main index.html file. We also added the ScrollReveal library to the project so that we could add simple reveal animations to the website.



We created the basic ScrollReveal setup in the JavaScript file and added settings for the animation distance, duration, delay and reset option.



After setting up ScrollReveal, we added reveal animations to different sections of the website. The Home text, section headings, watch cards, collection cards, feature cards, About section, New Arrivals, Best Sellers, Reviews and Newsletter sections were given reveal effects.



We initially used a longer animation duration, but it felt a little slow while scrolling through the website. We reduced the duration and delay so that the sections reveal faster while still keeping the animation smooth.



The animations were tested by scrolling through the website and the reveal effects were working correctly without any errors in the browser console.
