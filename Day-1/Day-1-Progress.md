# **FWC (Fake Watch Company)**

Daily Project Progress



###### **Day: 1**

###### Date: **11/09/2026**



Today we started working on the FWC (Fake Watch Company) website. We finalized the main idea and the basic design of the website before starting the coding.



We created the project folder and the required files. We started with the basic HTML structure and then worked on the header section.



The header contains the FWC logo, navigation links for Home, Watches, Collections, About and Contact, along with Sign Up and Sign In buttons. A menu icon was also added to the header.



After completing the HTML part of the header, we added the CSS for the layout, colors, spacing and buttons.



We also added hover effects to the navigation links. A line appears below the navigation link when the mouse is placed over it. This was done using the CSS ::after pseudo element.



After the header, we started the Home section. The section contains the FWC name, the main heading, a short description and the Explore Watches button. A watch image was also added as the background of the section.



A dark overlay was added over the background image so that the text can be seen clearly.



The basic styling for the Home section was also completed, including the font sizes, spacing, colors and button styling.
