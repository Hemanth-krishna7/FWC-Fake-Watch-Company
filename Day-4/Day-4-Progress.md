# **FWC (Fake Watch Company)**

Daily Project Progress

###### **Day: 4**

###### Date: **14/09/2026**



Today we continued working on the FWC (Fake Watch Company) website by adding the About FWC section.



The About section was designed using a two-column layout. One side contains a watch image and the other side contains the About FWC heading, description and Discover FWC button.



We added a dark background to the section to match the premium look of the website. A hover effect was also added to the watch image so that it slightly zooms when the cursor is placed over it.



After completing the About section, we created the New Arrivals section.

The New Arrivals section contains four watches which are FWC Horizon, FWC Monarch, FWC Vanguard and FWC Signature. Each watch is displayed inside a separate card with an image, name, description, price and View Details button.



We used a four-column grid layout for the cards and added borders, spacing, rounded corners and hover effects. The watch images were also adjusted to fit properly inside the cards.



We then created the Best Sellers section with three watches which are FWC Royal, FWC Imperial and FWC Elite.



The Best Sellers section uses a dark background with darker cards to give it a different appearance from the New Arrivals section. Each card contains a watch image, name, description, price and View Details button.

Hover effects were added to the Best Sellers cards so that they move slightly upward and show a shadow when hovered.



We also adjusted the watch images so that they fill the available image area properly and are clearly visible.
