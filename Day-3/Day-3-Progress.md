# **FWC (Fake Watch Company)**

Daily Project Progress

###### **Day: 3**

###### Date: **13/09/2026**

Today we continued working on the FWC (Fake Watch Company) website by adding the Collections section.



We added four collections which are Classic, Chronograph, Luxury and Sport. Each collection contains an image, a short description and an Explore Collection button.



We used a two-column grid layout for the collection cards. We also added a dark overlay over the images so that the text can be seen clearly.



After completing the Collections section, we added the Features section.



The Features section contains three features which are Precision, Premium Quality and Timeless Design. We used Boxicons for the icons in these cards.

We added circular backgrounds around the icons and also added hover effects. When the cursor is placed over the icons, their background and color change.



Hover effects were also added to the feature cards so that they move slightly upward and show a shadow when hovered.



The styling was kept similar to the other sections of the website by using the same fonts, colors, buttons and spacing.
