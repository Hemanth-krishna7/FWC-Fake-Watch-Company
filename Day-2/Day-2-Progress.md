# **FWC (Fake Watch Company)**

Daily Project Progress



###### **Day: 2**

###### Date: **12/09/2026**



Today we continued working on the FWC (Fake Watch Company) website by creating the Featured Watches section.



We added a new section below the Home section to display the watches available in the FWC collection. We decided to use seven watch cards instead of six so that the section would have a slightly different layout.



Each watch card contains a watch image, watch name, short description, price and a View Details button.



We added CSS styling for the watch cards using grid layout, spacing, borders, background colors and rounded corners. Hover effects were also added to the cards so that they move slightly upward and show a shadow when the mouse is placed over them.



The watch images were adjusted so that the complete watch is visible inside each card without unnecessary cropping.



We also added borders to the View Details buttons so that the buttons remain clearly visible when the hover effect changes their background color.



The seventh watch card was placed in the center below the first six cards to give the Featured Watches section a different layout.



We also made the header stay visible at the top while scrolling through the website.
